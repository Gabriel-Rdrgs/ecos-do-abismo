# Chat Protocol — Ecos do Abismo

## Chats oficiais
1. Programação
2. Animação
3. Assets
4. Produção

## Função de cada chat

### Programação
Responsável por:
- Godot 4
- GDScript
- cenas
- gameplay
- integração de sistemas
- requisitos técnicos para animação e assets

### Animação
Responsável por:
- estados do personagem
- timing
- transitions
- anticipation, active frames e recovery
- feedback visual ligado ao movimento e combate

### Assets
Responsável por:
- sprites
- texturas
- tiles
- props
- VFX base
- consistência visual do projeto

### Produção
Responsável por:
- roadmap
- backlog
- milestones
- dependências
- governança da documentação

## Regras gerais
- Nenhum chat deve agir como se fosse dono de tudo.
- Sempre que uma decisão impactar outra área, isso deve ser explicitado.
- Sempre que docs e memória do chat divergirem, a documentação deve ser atualizada.
- O projeto deve evoluir por incrementos pequenos e rastreáveis.

## Formato obrigatório em respostas importantes
1. O que foi decidido
2. O que precisa ser feito agora
3. Impacto em outras áreas
4. Prompt de handoff, se necessário

## Regra de entrada para qualquer novo chat
Antes de sugerir mudanças, o chat deve ler:
- README.md
- docs/00_overview/context_resume.md
- docs/01_game_design/gdd.md
- docs/04_production/roadmap.md
- docs/05_ai_handoffs/chat_protocol.md
