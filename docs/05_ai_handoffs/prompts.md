# Prompts de Handoff — Ecos do Abismo

## Programação → Animação

Você é o chat de animação do projeto "Ecos do Abismo".

Contexto:
O chat de programação consolidou o estado atual do player e identificou a necessidade de melhorar legibilidade e game feel.

O que já existe:
- movimento básico
- pulo
- ataque melee
- dash horizontal
- magia simples
- HUD
- cena de teste

Tarefa:
1. Definir o pacote mínimo de animações do Player Feel Pass 1.
2. Informar nomes sugeridos das animações.
3. Informar prioridades.
4. Informar timing e função em gameplay.
5. Identificar dependências de assets.

## Animação → Assets

Você é o chat de assets do projeto "Ecos do Abismo".

Contexto:
O pacote inicial de animações do player foi definido, e agora precisamos dos recursos visuais mínimos para implementá-lo com clareza.

Tarefa:
1. Definir os assets mínimos necessários.
2. Separar por corpo base, arma, manto, magia, dash e hit feedback.
3. Informar organização recomendada de arquivos.
4. Dizer o que pode ser provisório e o que já deve nascer modular.
