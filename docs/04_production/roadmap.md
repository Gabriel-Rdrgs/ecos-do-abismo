# Roadmap — Ecos do Abismo

## Fase 0 — Estruturação do projeto
- Criar repositório remoto
- Criar README, CHANGELOG e .gitignore
- Migrar planejamento para GDD
- Criar documentação operacional
- Definir chats/agentes e seus protocolos
- Padronizar handoffs

## Fase 1 — Protótipo técnico jogável
- Consolidar player base
- Consolidar HUD
- Consolidar magia simples
- Consolidar dash e ataque
- Consolidar dummy/inimigo básico
- Validar testes iniciais de combate

## Fase 2 — Player Feel Pass 1
- Adicionar animações básicas do player
- Adicionar feedback visual de hit
- Adicionar feedback de dash
- Adicionar feedback de cast
- Ajustar timings principais
- Melhorar sensação do combate

## Fase 3 — Slice inicial jogável
- Construir Ruínas Cinzentas como primeiro fluxo jogável [file:1]
- Integrar tutorial implícito
- Inserir primeiro gate de habilidade
- Criar primeiro chefe placeholder
- Validar loop básico de progressão

## Fase 4 — Expansão controlada
- Inimigos adicionais
- UI mais madura
- Assets modulares
- Estrutura de níveis mais robusta
- Integração mais forte entre art, animação e gameplay

## Critérios para avançar
Só avançar de fase quando a fase anterior estiver estável, documentada e testável.
