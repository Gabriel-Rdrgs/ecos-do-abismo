# Art Bible — Ecos do Abismo

## Objetivo
Definir a direção visual inicial do projeto para manter consistência entre concepts, texturas, sprites, VFX e cenário.

## Identidade visual
Ecos do Abismo deve transmitir:
- ruína;
- melancolia;
- mistério;
- espiritualidade corrompida;
- decadência de civilizações antigas [file:1].

O mundo deve parecer antigo, quebrado e carregado de memória.

## Referência de tom
Mistura de:
- dark fantasy;
- ruínas sagradas;
- ecos espirituais;
- decadência monumental;
- atmosfera opressiva com pequenos contrastes luminosos.

## Linguagem visual
### Formas
- silhuetas legíveis;
- formas levemente angulares;
- pedra, metal gasto, tecido rasgado;
- arquitetura colossal;
- elementos quebrados e assimétricos.

### Materiais principais
- pedra antiga rachada;
- metal oxidado;
- tecido gasto;
- cristal;
- energia espectral;
- fogo abissal;
- luz sagrada fragmentada.

## Paleta-base
### Base
- cinzas frios;
- preto desbotado;
- off-white envelhecido;
- dourado gasto;
- marrom escuro mineral.

### Acentos
- teal espectral para eco/memória;
- branco-dourado para Conclave;
- violeta escuro ou azul profundo com muito controle;
- laranja ígneo para áreas de ruptura.

## Personagem principal
O Eco-Vagante deve parecer:
- frágil, mas persistente;
- parcialmente humano, parcialmente ruína;
- alguém que carrega energia interna instável;
- um sobrevivente, não um herói limpo [file:1].

### Diretrizes
- silhueta clara;
- proporções funcionais para jogo 2D;
- roupa em camadas;
- elementos rasgados e gastos;
- brilho de eco usado com moderação;
- design legível em movimento lateral.

## Primeiro bioma visual
### Ruínas Cinzentas
A primeira área deve comunicar imediatamente a identidade do jogo [file:1]:
- pedra colossal rachada;
- estátuas quebradas;
- ruínas silenciosas;
- ecos flutuando;
- sensação de tutorial sombrio.

## Texturas e assets iniciais
Priorizar:
1. textura de chão de pedra antiga;
2. blocos/tiles simples de ruína;
3. fundo provisório coerente;
4. personagem provisório legível;
5. VFX simples de ataque, dash e eco.

## Regras de produção visual
- legibilidade acima de detalhe;
- consistência acima de variedade excessiva;
- assets provisórios podem ser simples, mas devem respeitar o tom;
- evitar visual genérico de fantasia medieval limpa;
- efeitos brilhantes devem existir como contraste, não como regra.

## Regras para assets temporários
- podem ser simplificados;
- devem ter boa leitura lateral;
- devem servir gameplay;
- não devem quebrar o tom do projeto.

## Observações
A direção visual final evoluirá com protótipos, testes e concepts. Este documento serve como guia base para manter unidade estética desde o início.
